Dentro do Style.css

Como Usar?

Basicamente, a estrutura do CSS externo é a mesma utilizada no CSS interno. Você seleciona a tag ou o elemento que deseja modificar, abre e fecha as chaves e adiciona as propriedades CSS com suas respectivas configurações dentro delas.

A única diferença é que, em vez de escrever esse código dentro da tag `style` no HTML, você o coloca diretamente no arquivo `.css`.

Regras

As At-rules são regras especiais do CSS que começam com o símbolo @. Elas permitem adicionar configurações e funcionalidades diferentes à sua folha de estilos, indo além das alterações visuais comuns.

Existem diversas At-rules, cada uma com uma finalidade específica. Algumas permitem importar outros arquivos CSS, adicionar fontes personalizadas, criar animações e até adaptar o visual do site conforme o tamanho da tela.

Entre as mais utilizadas estão

  • @charset Define a codificação de caracteres.
  • @import Importa outros arquivos CSS.
  • @media Aplica estilos conforme as características da tela ou dispositivo.
  • @font-face Adiciona fontes personalizadas.
  • @keyframes Cria animações.
  • @supports Verifica o suporte do navegador a propriedades CSS.

Uma das mais importantes é a @media, que permite criar estilos específicos para diferentes tamanhos de tela. Isso é muito útil para desenvolver sites responsivos, que se adaptam tanto a computadores quanto a celulares e tablets.

Basicamente, as At-rules são instruções especiais que ampliam as possibilidades do CSS e ajudam a criar páginas mais completas e dinâmicas.
