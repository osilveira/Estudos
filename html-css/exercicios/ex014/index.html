CSS - Estilo Externo

Por que usar o Externo?

O CSS externo é o mais recomendado, principalmente quando você possui mais de uma página no seu site. A diferença entre o CSS interno e o externo fica ainda mais evidente quando pensamos em um projeto com várias páginas.

Vamos supor que você tenha 15 páginas HTML e queira manter o mesmo design em todas elas. Se utilizar o CSS interno, precisará criar uma tag style em cada página e repetir todas as configurações. Isso seria bastante trabalhoso!

Com o CSS externo, você pode concentrar todas as configurações de estilo em um único arquivo .css e vinculá-lo às 15 páginas utilizando a tag link:css. Assim, se quiser alterar alguma característica visual do site, basta modificar o arquivo CSS, e todas as páginas vinculadas a ele receberão as alterações.
