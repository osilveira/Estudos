Inserindo Vídeos Hospedados Localmente

Para adicionar um vídeo ao seu site, basta utilizar a tag video e colocar o endereço do arquivo de vídeo no atributo src. Em seguida, podemos definir a largura do vídeo utilizando o atributo width. Neste exemplo, optei por utilizar 500 pixels de largura.

Por fim, adicionamos o atributo controls dentro da tag video, permitindo que o usuário tenha acesso aos controles de reprodução, como o botão de play e pausa.

Caso queira, também é possível adicionar o atributo poster que serve para definir uma capa para o vídeo.

Primeiramente, é importante entender que existem diferentes formatos de vídeo, como MP4, WebM e Ogg. Cada navegador possui compatibilidade com determinados formatos e codecs, ou seja, um vídeo que funciona em um navegador pode não funcionar em outro.

Por esse motivo, é recomendado disponibilizar o vídeo em diferentes formatos, permitindo que o navegador escolha automaticamente uma das versões compatíveis com ele. Assim, aumentamos as chances de o vídeo funcionar corretamente para todos os usuários.

Para disponibilizar vídeos em diferentes formatos, criaremos novamente a tag video, mas deixaremos nela apenas os atributos width e controls. Dentro das tags video e /video, adicionaremos uma tag source para cada versão do vídeo.

No atributo src, colocaremos o caminho do arquivo, enquanto no atributo type informaremos seu formato:

  • MP4 e M4V: video/mp4
  • WebM: video/webm
  • OGV: video/ogg

Por fim, adicionaremos um parágrafo com uma mensagem para o usuário caso o navegador não consiga reproduzir nenhum dos formatos disponibilizados.

Obs: Se você utilizar o atributo loop dentro da tag video você deixa o video em loop

Inserindo Vídeos hospedados no Youtube

Para adicionar um vídeo do YouTube ao seu site, é muito simples! Basta acessar o vídeo desejado, clicar em "Compartilhar" e, em seguida, selecionar a opção "Incorporar". O YouTube disponibilizará um código HTML que você deverá copiar e colar no código do seu site. Pronto! O vídeo ficará incorporado à sua página.
