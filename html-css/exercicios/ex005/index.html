Hierarquia dos Títulos


Para criar um título, você precisa usar a tag h1. Mas qual é a diferença entre ela e as tags h2, h3, h4 e assim por diante? Basicamente, o que define qual tag usar é a hierarquia. Pense nelas como a estrutura de um livro: o h1 é o título principal da página, o h2 representa as grandes seções, o h3 detalha um subópico dessa seção, e por aí vai.
