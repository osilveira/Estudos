Estilos Inline

Existem diversas formas de estilizar um site, e uma delas é configurar os estilos diretamente na tag body. Apesar de eu não gostar muito dessa abordagem, pois prefiro criar um arquivo CSS separado e vinculá-lo ao HTML usando a tag link rel="stylesheet", vamos fazer dessa forma por enquanto. Para isso, você precisa criar a tag style dentro da tag head e colocar as especificações desejadas, como background-color, que permite definir a cor de fundo da página.

Uma das principais desvantagens do CSS inline é que você precisa adicionar o atributo "style" individualmente em cada tag que deseja modificar. Por exemplo, se quiser deixar um parágrafo justificado, será necessário adicionar "style" dentro da própria tag "p" e utilizar a propriedade "text-align" com o valor "justify".
