CSS - Estilos Internos

Para criar um estilo interno no código, basta adicionar a tag style dentro da tag head. Por uma questão de organização, costumo colocá-la logo abaixo da tag title.

Entre style e /style, você pode definir os estilos das tags e elementos que deseja modificar. Vamos supor que você queira alterar a cor de fundo da página. Para isso, será necessário selecionar a tag body. Dentro da tag style, você digitaria body {}, colocando as configurações desejadas entre as chaves.

Esse mesmo princípio vale para outras tags: basta escrever o nome da tag, abrir e fechar as chaves e adicionar as propriedades CSS que deseja modificar.

Por exemplo:

body {
background-color: bisque;
}

Principais Diferenças

A principal diferença entre o CSS interno e o inline é que o inline obriga você a editar individualmente cada elemento que deseja modificar.

Por exemplo, imagine que você queira mudar a fonte de todos os seus parágrafos. Utilizando o CSS inline, seria necessário adicionar as configurações em cada tag p. Mas e se o seu código tiver 50 parágrafos? Exatamente! Você teria que repetir o mesmo código 50 vezes.

Já utilizando o CSS interno, você consegue modificar todos os parágrafos de uma só vez, sem precisar repetir as configurações.

Voltando ao exemplo dos parágrafos, caso queira alterar a fonte de todos eles para Arial e deixar o texto justificado, basta escrever:

p {
font-family: Arial, Helvetica, sans-serif;
text-align: justify;
}

Claro, você também pode definir a família e o tamanho da fonte diretamente na tag `body`. Dessa forma, essas configurações serão herdadas pelos elementos de texto dentro dela, incluindo os parágrafos e os títulos, desde que não tenham estilos próprios sobrescrevendo essas propriedades.
