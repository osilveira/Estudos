Imagens que se adaptam sozinhas

Neste exercício, baixei três imagens de tamanhos diferentes e as separei em três categorias: pequena, média e grande. O objetivo deste HTML é fazer com que a imagem exibida mude de acordo com o tamanho da tela do dispositivo. A imagem pequena será utilizada em celulares, a média em tablets e a grande em notebooks e televisores.
Dito isso, experimente abrir esta página em diferentes dispositivos ou redimensionar a janela do navegador para testar como funciona a exibição dinâmica das imagens!

Para criar imagens dinâmicas no HTML, utilizamos a tag picture, que permite exibir imagens diferentes de acordo com as condições definidas. Dentro dela, colocamos a tag img, que será responsável por exibir a imagem principal. Neste exemplo, utilizaremos a imagem maior, chamada `foto-g.png`, que possui 1000 pixels. Acima da tag img, adicionaremos a tag source:media:type, utilizando os atributos media e srcset para definir as condições em que cada imagem deverá ser exibida. Dessa forma, o navegador poderá selecionar a imagem mais adequada de acordo com o tamanho da tela.

Primeiramente, faremos uma pequena alteração no atributo media. Por uma escolha pessoal, comecei trabalhando com a imagem maior. Como estamos configurando a imagem grande, utilizaremos max-width para definir a largura máxima em que essa condição será aplicada. Assim, ao atingir essa largura ou um valor inferior, o navegador poderá selecionar outra imagem, caso exista uma condição correspondente.
Como dito anteriormente, a imagem foto-g.png possui 1000 pixels de largura. Porém, queremos evitar que ela ocupe mais espaço do que o disponível na tela e provoque uma rolagem horizontal, faremos uma pequena alteração no atributo media. Por uma escolha pessoal, comecei trabalhando com a imagem maior, mas é comum organizar as condições das imagens responsivas começando pela menor.
Como estamos configurando a imagem grande, mudaremos o media="(min-width: )" para media="(max-width: )" assim definiremos a largura máxima em que essa condição será aplicada. Ao atingir essa largura ou um valor inferior, o navegador poderá selecionar outra imagem, caso exista uma condição correspondente.

Como dito anteriormente, a imagem foto-g.png possui 1000 pixels de largura. Porém, queremos evitar que ela ocupe mais espaço do que o disponível na tela. Por isso, definiremos o limite de troca em 1050 px, acrescentando 50 px.

Nossa condição ficará assim: media="(max-width: 1050px)".

Por fim, dentro do srcset colocaremos a imagem que substituirá a foto-g.

Colocando Áudios

Para reproduzir áudios no seu site, existem duas maneiras. A primeira e mais simples é utilizar a tag "audio". Para exibir os controles de reprodução, como os botões de play e pausa, utilizamos o atributo "controls". Também podemos adicionar o atributo "autoplay", que tenta reproduzir o áudio automaticamente assim que possível, sem que o usuário precise iniciar a reprodução manualmente.

A outra maneira é utilizar a tag audio e, dentro dela, adicionar a tag source:src. No atributo src, colocamos o caminho do arquivo de áudio, enquanto no atributo type informamos o formato do arquivo, como audio/mpeg para arquivos MP3.
