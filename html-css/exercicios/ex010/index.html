Links Externos

Um link externo é um link que direciona o usuário para outro site. Para criá-lo, utilizamos a tag e o atributo href, no qual informamos o endereço da página desejada. Dessa forma, podemos transformar uma palavra ou frase em um link clicável.

Por exemplo: acesse meu canal no YouTube para me ver perdendo a sanidade com filmes ruins!

Perceba que, ao clicar no link, o YouTube foi aberto em uma nova aba, sem substituir a página do meu site. Isso foi possível graças ao atributo target="_blank", que indica ao navegador que o link deve ser aberto em uma nova aba ou janela. Além disso, utilizei o atributo rel="external" para indicar que o link direciona o usuário para um site externo.

Links Internos para Outra Pasta

Criar um link interno para uma página que está em outra pasta é simples! Ao escrever o atributo href dentro da tag a, pressione Ctrl + Espaço para que o VS Code sugira caminhos e arquivos disponíveis no projeto.

Em seguida, selecione a pasta onde está localizada a página desejada. Depois, pressione Ctrl + Espaço novamente para visualizar e selecionar o arquivo HTML que você deseja acessar.

Links para Download

Neste exemplo, disponibilizei o link para o meu TCC, permitindo que você baixe o documento em PDF ou em um arquivo compactado no formato ZIP.
Para disponibilizar um arquivo para download, utilizamos a mesma tag a que usamos para criar links. Porém, adicionamos o atributo "download", informando o nome desejado para o arquivo baixado. Também podemos utilizar o atributo "type" para indicar o tipo de arquivo, como "application/pdf" para PDFs ou "application/zip" para arquivos ZIP.

Assim, você pode compartilhar arquivos para download diretamente pelo seu site!
