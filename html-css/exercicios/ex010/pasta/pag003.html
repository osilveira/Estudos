Página de outra pasta

Estamos na página três, mas você reparou que ela está em uma pasta diferente da página anterior? Então, como podemos voltar para a página anterior?

É simples! Dentro do atributo href da tag , utilizamos ../ para voltar um nível na estrutura de pastas. Em seguida, informamos o nome do arquivo HTML que queremos acessar.
