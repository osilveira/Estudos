Principais Formatações

Negrito/Destaque

Existem duas maneiras de fazer isso no HTML: a forma semântica e a não semântica.
A forma não semântica serve apenas para deixar o texto visualmente em negrito. Para isso, utilizamos a tag b.

Já na forma semântica, utilizamos a tag strong, que indica que o texto possui grande importância ou relevância dentro do conteúdo. Por padrão, os navegadores também exibem esse texto em negrito.

Texto Marcado

Podemos criar um texto marcado usando a tag MARK e consigo mudar a cor dela usando style dentro da tag

Texto Deletado/Riscado

Fiz um texto excluido, que significaria que ele pode ser lido, mas deve ser ignorado, usando a tag del.

Texto Adicionado/Sublinhado

Podemos colocar um texto que mostre para todos que ele foi inserido depois usando a tag ins.
