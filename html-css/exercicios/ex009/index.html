Trabalhando com Listas

Listas Ordenadas

Para criar uma lista ordenada no HTML, utilizamos a tag ol, que organiza os itens em uma sequência numerada. Para adicionar cada item à lista, utilizamos a tag li. Usando o type você muda a sequência da lista.

  1. Acordar
  2. Arrumar a cama
  3. Tomar banho
  4. Tomar café
  5. limpar a mesa
  6. Gravar vídeo para o Youtube

Listas Não Ordenadas

As listas não ordenadas são utilizadas quando a sequência dos itens não é importante. Para criá-las, utilizamos a tag ul, que exibe os itens com marcadores em vez de números. Para adicionar cada item à lista, utilizamos a tag li. Para mudar o tipo da lista você adiciona o type dentro da primeira tag ul, tendo três opções disc, square e circle (O que foi usado) type="circle"

  • Ver um filme
  • Escrever roteiro sobre o filme
  • Programar
  • Gravar um vídeo

Juntando Listas 1.0

Também é possível criar listas dentro de outras listas, formando sublistas. Além disso, podemos controlar a numeração de uma lista ordenada utilizando o atributo start na tag

    . Com ele, definimos o número inicial da lista, permitindo que a numeração continue de onde a lista anterior parou.
